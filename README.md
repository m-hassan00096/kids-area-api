# Kids Area API

Backend repository for the Kids Area Management System.

## Start here — new conversation or AI assistant

**Always read the [living Kids Area Conversation Handoff](docs/00-overview/kids-area-conversation-handoff.md) first** when resuming project discussions or implementation. It records the latest verified GitHub state, approved decisions, unresolved questions and next action.

Then verify the current branch/PR state and read the relevant canonical [AI Workflow Rules](docs/02-standards/ai-workflow-rules.md), [Project Overview](docs/00-overview/project-overview.md), [Backend Architecture](docs/01-architecture/backend-architecture.md), module reference and feature specs.

See [AGENTS.md](AGENTS.md) for the short assistant reading/maintenance protocol. The handoff is a **living summary**, not a substitute for canonical approved specifications or verification of actual code/test status. GitHub-based assistants should keep it current at major decisions/milestones, through the normal review/approval workflow.

**For a new ChatGPT chat:** ask it to read the [handoff on `develop`](https://github.com/m-hassan00096/kids-area-api/blob/develop/docs/00-overview/kids-area-conversation-handoff.md) using the connected GitHub app. ChatGPT does not automatically load this repository in every new conversation.
